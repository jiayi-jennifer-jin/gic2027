# Gender-inclusive Cities — conference website

Static, responsive website ready for **GitHub Pages** (no build step, no Jekyll, no JavaScript required).

## Publish

1. Create a public GitHub repository, for example `gender-inclusive-cities`.
2. Upload `index.html`, the `assets` directory, `.nojekyll` and `README.md` to the repository root.
3. Open **Settings → Pages**, choose **Deploy from a branch**, `main`, `/(root)`, and save.
4. Visit `https://YOUR-USERNAME.github.io/gender-inclusive-cities/` after publishing.

## Edit

- `index.html` → dates, venue, speaker names, chair information, organiser and email.
- `assets/style.css` → theme colours at the top of the file (`--paper`, `--ink`, `--blue`, `--lavender`, `--coral`).
- `assets/favicon.svg` → simple custom icon.
