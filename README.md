
# Gender-inclusive Cities — Conference website v4

This is a static website for GitHub Pages. The top section matches the supplied mock-up: three conference facts, full-width night skyline, white/ochre text, and four partner marks displayed once.

## Deploy

Upload the *contents of this folder* directly to your repository root (not a nested subfolder). Commit changes. If GitHub Pages is configured to `Deploy from a branch` with `main` and `/(root)`, it redeploys automatically. Use Ctrl + Shift + R to refresh.

## Assets and publication checks

* `assets/skyline-original.webp` is the user's exact image (940×507).
* `assets/skyline-upscaled.webp` is a 2820×1521 Lanczos upscale with gentle sharpening, **not** an authentic higher-resolution original. It cannot restore detail that is missing from the source.
* `assets/logo-*.png` files are provisional transparent white logo cut-outs processed from the user-provided visual mock-up. For the public-facing final site, replace each with the correct official monochrome/white artwork from its institution and confirm permitted use and partner attributions.
* Verify the night-skyline image is licensed/cleared for use on a public promotional website.
* Date, location, and abstract submission are taken from the new mock-up: 01–02 June 2027, TIC Glasgow, 01 Feb 2027.
* Speaker names are based on the application and must be reconfirmed before publishing.

HTML/CSS only. No Javascript framework. Helvetica-first system font stack with Arial fallback.
